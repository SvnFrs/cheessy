🎯 Chess Extension Fix - Turn Handling

🐛 The Bug: The extension only suggested moves for White because it confused player color (which side you play) with active color (whose turn it is to move).

📊 Before vs After

❌ BEFORE (Broken)

// Always used player color
var player_colour = "w";
fen_string += ` ${player_colour}`;

// Result:
// fen_string = "position... w"
// fen_string = "position... w" (WRONG!)
// Always suggests for White only!

✅ AFTER (Fixed)

// Now detects active turn
var active_color = determineActiveColor();
fen_string += ` ${active_color}`;

// Result:
// fen_string = "position... w"
// fen_string = "position... b" (CORRECT!)
// Alternates between both sides!

🎮 Board Orientation Handling

Normal Board (White Bottom)
⚫ Black - Top
⚪ White - Bottom
bottomTurn → White
topTurn → Black
Flipped Board (Black Bottom)
⚪ White - Top
⚫ Black - Bottom
bottomTurn → Black
topTurn → White

🔍 Detection Method

Primary Method: Check Chess.com clock indicators 
// Look for active player's clock
const bottomClock = document.querySelector('.clock-component.clock-bottom');
const topClock = document.querySelector('.clock-component.clock-top');

if (bottomClock.classList.contains('clock-player-turn')) {
    // Bottom player's turn
    return isFlipped ? 'b' : 'w';
}
else if (topClock.classList.contains('clock-player-turn')) {
    // Top player's turn
    return isFlipped ? 'w' : 'b';
}
Fallback Method: Alternate colors if detection fails 
// If can't detect, alternate from last known state
lastActiveColor = (lastActiveColor === 'w') ? 'b' : 'w';
return lastActiveColor;

🚀 How to Test

Test as White:
  1. Start a game as White on Chess.com
  2. Enable the Chessy extension
  3. Make your move → Extension suggests for Black
  4. After opponent moves → Extension suggests for White
Test as Black:
  1. Start a game as Black on Chess.com
  2. Enable the Chessy extension
  3. Wait for opponent to move → Extension suggests for Black (you)
  4. After your move → Extension suggests for White (opponent)
